# 結婚のご提案（提案書）

彼氏に渡す「結婚に関するご提案」を、仕事の提案書と同じ作法（ラベル → リード文 → 本文、山は1枚、色は1色）で組んだもの。全21枚。

| ファイル | 中身 |
|---|---|
| `結婚のご提案.pptx` | 本体。PowerPoint / Keynote / Googleスライドで開いて編集できる（フォントは Yu Gothic） |
| `結婚のご提案.pdf` | プレビュー用に書き出したPDF（代替フォントで描画しているため、書体だけ本体と異なる） |
| `deck.json` | 全ページの文章と構成。ここを直して再生成する |
| `build_deck_lite.py` | `deck.json` から .pptx を書き出すスクリプト。追加ライブラリ不要（Python 3 標準のみ） |

## 直し方

1. `deck.json` の文章を直す。`【 】` で囲んだ箇所は要記入（彼の名前・交際年数・出会った年・彼の口ぐせ・入籍候補日・役所名・証人・彼の得意なこと）
2. 再生成する

```bash
python3 build_deck_lite.py deck.json -o 結婚のご提案.pptx
python3 build_deck_lite.py deck.json --check   # 文字量の警告だけ見る
```

.pptx を直接開いて文字を書き換えても構わない。

## 構成（リード文だけ拾い読みできる順番）

| p | ラベル | 言いたいこと |
|---|---|---|
| 1 | 表紙 | 結婚に関するご提案 ／ 【彼の名前】御中 |
| 2 | ご提案サマリ | これからの毎日を、ふたりの共同プロジェクトに |
| 3 | INDEX | |
| 4 | 与件整理 | あなたの希望を、こう受け取っています |
| 5 | あなたの言葉と、私の解釈 | 口ぐせを「一緒なら」の省略形として聞いている |
| 6 | 現状整理（私調べ） | もう「試している段階」ではない |
| 7 | デプスインタビュー | 一番の理由は「理由がいらないこと」 |
| 8 | ふたりのジャーニー | 次のフェーズにだけ、まだ名前がついていない |
| 9 | 世の中の事実 | 「そのうち」は、予定ではない |
| 10 | 前提の確認 | 「そのうち」を今日に置き換える |
| 11 | 解決すべき課題 | 足りないのは愛情ではなく、日付。 ← 山 |
| 12 | キーメッセージ | 帰る場所を、ひとつに。 |
| 13〜14 | ご提案 | 婚姻届、共同提出 |
| 15 | ふたりの運用ルール（案） | お金・家事・ケンカ・時間 |
| 16 | 周囲の反応イメージ | 親友・母・同僚・彼の友人 |
| 17 | KPIの考え方 | おやすみ365日・旅行1回以上・持ち越したケンカ0回 |

| 19 | スケジュール（案） | 年内の入籍を想定 |
| 20 | 体制図 | 提案者と決裁者 |
| 21 | 締め | 帰る場所を、ひとつに。 |

発表用の手元メモは各スライドのノート欄に入っている。
