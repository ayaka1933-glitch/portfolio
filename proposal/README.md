# ふたりの計画のご提案

彼に渡す「ふたりの計画のご提案」。提案の形をとった計画書（たたき台）で、赤を入れて返してもらう前提。全26枚。見た目は白地・墨文字にミント／黄／コーラルを強く使う「bold」テーマ。表紙・章扉・締めだけ、やわらかいピンクとハートの飾りを入れている。文章はです・ます調。

| ファイル | 中身 |
|---|---|
| `ふたりの計画のご提案.pptx` | 本体。PowerPoint / Keynote / Googleスライドで開いて編集できる（フォントは Yu Gothic） |
| `ふたりの計画のご提案.pdf` | プレビュー用に書き出したPDF（代替フォントで描画しているため、書体だけ本体と異なる） |
| `deck.json` | 全ページの文章と構成。ここを直して再生成する |
| `build_deck_lite.py` | `deck.json` から .pptx を書き出すスクリプト。追加ライブラリ不要（Python 3 標準のみ） |

## 直し方

1. `deck.json` の文章を直す。フォントを変えたいときは `meta.font` に書体名を入れる（例：`"font": "Hiragino Sans"`）
2. 再生成する

```bash
python3 build_deck_lite.py deck.json -o ふたりの計画のご提案.pptx
python3 build_deck_lite.py deck.json --check   # 文字量の警告だけ見る
```

.pptx を直接開いて文字を書き換えても構わない。

`meta.theme` は `bold`（白地・3色）／`pop`（クリーム地・角丸・パステル）／`wine` `navy` など（提案書の作法どおりの1色）から選べる。各ページの `close` は下に置く言い切りの一文。`solo` レイアウトは1ページ1項目で、`no` の数字と `title` の一言を大きく出す（`fill` を渡すと全面色の扉になる）。`flow` は手順の箱を矢印でつなぐ図、`rings` は同心円＋条件の一覧。

表紙・扉・締めの書体は `meta.font_display` で変えられる（既定は Hiragino Maru Gothic ProN。Windows なら `UD デジタル 教科書体 NP-B` など、入っていない書体は自動で置き換わる）。ハートの位置は `build_deck_lite.py` の `HEART_SPOTS`。

発表用の手元メモは各スライドのノート欄に入っている。
