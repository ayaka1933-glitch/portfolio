# ふたりの計画のご提案

彼に渡す「ふたりの計画のご提案」。提案の形をとった計画書（たたき台）で、赤を入れて返してもらう前提。全11枚。見た目はポップ寄り（クリーム地・角丸・4色）。

| ファイル | 中身 |
|---|---|
| `ふたりの計画のご提案.pptx` | 本体。PowerPoint / Keynote / Googleスライドで開いて編集できる（フォントは Yu Gothic） |
| `ふたりの計画のご提案.pdf` | プレビュー用に書き出したPDF（代替フォントで描画しているため、書体だけ本体と異なる） |
| `deck.json` | 全ページの文章と構成。ここを直して再生成する |
| `build_deck_lite.py` | `deck.json` から .pptx を書き出すスクリプト。追加ライブラリ不要（Python 3 標準のみ） |

## 直し方

1. `deck.json` の文章を直す。`【彼の名前】` は要記入（表紙・前提・決めること の3か所）
2. 再生成する

```bash
python3 build_deck_lite.py deck.json -o ふたりの計画のご提案.pptx
python3 build_deck_lite.py deck.json --check   # 文字量の警告だけ見る
```

.pptx を直接開いて文字を書き換えても構わない。

## 構成

| p | ラベル | 言いたいこと |
|---|---|---|
| 1 | 表紙 | ふたりの計画のご提案 ／ 【彼の名前】さん 御中 |
| 2 | はじめに | これはたたき台。赤ペン歓迎 |
| 3 | いまのふたり | 年齢・仕事・住まい・これから。彼の側は空欄 |
| 4 | ゴール | 30歳までに入籍、32歳までに子ども一人。削らないのは写真と新婚旅行 |
| 5 | ロードマップ | 2026年10月〜2029年。分かれ道は2027年後半の1か所だけ |
| 6 | 住まい | 分かれ道は家賃補助。最初の家は子ども前提の広さで、引っ越しは1回に |
| 7 | 生活費 | 家賃・共同口座・削らないもの・後回し（金額はこのページだけ） |
| 8 | 私のお金のこと | 転職で年収が上がる分が原資、NISAは崩さない、カンヌは私側 |
| 9 | 決めること | 期限つきの未決事項。彼の宿題は1行だけ（黄色） |
| 10 | 約束 | 仕事・自由・家事・ケンカ |
| 11 | 締め | この紙を、たたき台にしてください。次に開くのは2027年3月 |

`meta.theme` を `wine` や `navy` に変えると、提案書らしい白地・1色の見た目に戻る。

発表用の手元メモは各スライドのノート欄に入っている。
